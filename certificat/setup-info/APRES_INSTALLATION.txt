INSTALLATION TERMINÉE — POS CONNECT SERVEUR LOCAL
==================================================

POS Connect a été installé avec succès sur votre ordinateur.

SERVICES DÉMARRÉS
-----------------
  ✔ POS_Connect_MySQL  — Base de données  (port 3307, local uniquement)
  ✔ POS_Connect_API    — Serveur API      (port 9003, jamais exposé directement)
  ✔ POS_Connect_Nginx  — Proxy HTTPS      (port 443, seul point d'accès réseau)

  Ces trois services démarrent automatiquement avec Windows, dans cet
  ordre (chacun dépend du précédent).
  Pour les gérer : Panneau de configuration → Outils d'administration → Services
  Ou plus simple : lancez "Gestionnaire POS Serveur" depuis le menu Démarrer.

PROCHAINES ÉTAPES
-----------------

  1. OUVRIR L'APPLICATION POS CONNECT
     Lancez l'application POS Connect sur ce poste ou sur un poste client
     (installeur séparé "POSConnect-Client-Setup.exe").

  2. PREMIÈRE CONFIGURATION (WIZARD)
     Au premier lancement, l'assistant d'installation vous guidera pour :
       - Choisir le mode (Serveur / Client / Les deux)
       - Configurer la base de données (SQLite ou MySQL)
       - Créer le compte administrateur de votre boutique
       - Connecter votre abonnement cloud (optionnel)

  3. CONNEXION DEPUIS UN AUTRE POSTE
     Rien à saisir dans la majorité des cas : les postes clients détectent
     automatiquement ce serveur via "infini-post.local" sur le réseau local
     et s'y connectent en HTTPS.

     Si l'auto-découverte échoue (réseau qui bloque le multicast), saisissez
     l'adresse IP de ce serveur dans l'app cliente — elle continuera de se
     connecter en HTTPS avec le certificat épinglé, jamais en clair.
     Pour connaître cette adresse IP :
       Ouvrez l'invite de commandes → tapez : ipconfig
       Notez l'adresse IPv4 de la carte réseau locale.

  4. CERTIFICAT SSL (CONNEXION SÉCURISÉE)
     Un certificat auto-signé a été installé pour sécuriser les connexions
     sur le réseau local. L'application le reconnaît automatiquement (aucun
     avertissement). Si vous ouvrez l'adresse dans un navigateur classique
     à la place, un avertissement de sécurité s'affichera — c'est normal,
     cliquez sur "Continuer quand même".

FICHIERS IMPORTANTS
-------------------
  Config serveur   : C:\ProgramData\POS_Connect\pos_server.ini
  Logs API         : C:\ProgramData\POS_Connect\api-stdout.log / api-stderr.log
  Logs MySQL       : C:\ProgramData\POS_Connect\logs\mysql-error.log
  Logs Nginx       : C:\Program Files\POS_Connect\nginx\logs\

DÉSINSTALLATION
---------------
  Panneau de configuration → Programmes → POS Connect → Désinstaller
  Ou relancez ce setup et choisissez "Désinstaller".
