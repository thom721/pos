AVANT D'INSTALLER POS CONNECT — INFORMATIONS IMPORTANTES
=========================================================

Bienvenue dans l'installation de POS Connect — Serveur Local.

PRÉREQUIS SYSTÈME
-----------------
  Systeme d'exploitation : Windows 10 / 11 (64 bits)
  Processeur             : Intel/AMD x64, minimum 2 cœurs
  Mémoire RAM            : 4 Go minimum (8 Go recommandé)
  Espace disque          : 2 Go libres minimum
  Réseau                 : Connexion locale requise pour les postes clients

CE QUI SERA INSTALLÉ
--------------------
  - POS Connect Serveur (API FastAPI compilée)
  - MySQL (base de données locale) — sauf si vous choisissez SQLite
  - Nginx (reverse proxy HTTPS)
  - Certificat SSL auto-signé (pour les connexions sécurisées sur le réseau local)
  - NSSM (gestionnaire de services Windows)
  - Diffusion mDNS "infini-post.local" (auto-découverte réseau local)
  - Trois services Windows démarrés automatiquement :
      · POS_Connect_MySQL  — base de données  (port 3307, local uniquement)
      · POS_Connect_API    — serveur API      (port 9003, jamais exposé directement)
      · POS_Connect_Nginx  — proxy HTTPS      (port 443, seul point d'accès réseau)

DOSSIER D'INSTALLATION
----------------------
  C:\Program Files\POS_Connect\
  Données et configuration : C:\ProgramData\POS_Connect\

AVANT DE CONTINUER, VÉRIFIEZ QUE :
-----------------------------------
  [ ] Vous avez les droits Administrateur sur ce poste
  [ ] Le port 443 n'est pas déjà utilisé par un autre logiciel (IIS, Apache,
      WampServer...) — sinon Nginx ne pourra pas démarrer
      (désactivez temporairement l'antivirus si nécessaire)
  [ ] Vous avez votre code d'abonnement POS Connect à portée de main
  [ ] Si vous prévoyez d'utiliser MySQL, aucune autre instance MySQL
      n'occupe déjà le port 3307 sur ce poste

POSTES CLIENTS (AUTRES ORDINATEURS)
------------------------------------
  Toute connexion se fait exclusivement en HTTPS, jamais en HTTP brut.
  Après l'installation du serveur, les autres postes du réseau local
  détectent automatiquement le serveur via "infini-post.local" (aucune
  IP à saisir). Si l'auto-découverte échoue sur ce réseau, l'app propose
  la saisie manuelle de l'adresse IP du serveur — elle se connecte alors
  quand même en HTTPS avec le certificat épinglé, jamais en clair.
